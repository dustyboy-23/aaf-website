<h2 id="gemini-in-google-workspace-the-productivity-agent">Gemini in Google Workspace: The Productivity Agent</h2><p>This is the Gemini agent most people will encounter first. If your company uses Google Workspace, Gemini can now:</p><ul><li><strong>Gmail:</strong> Draft replies, summarize threads, create follow-up reminders, categorize and prioritize your inbox</li><li><strong>Google Docs:</strong> Write drafts, edit for tone, create summaries, generate content from outlines</li><li><strong>Google Sheets:</strong> Create formulas, build charts, analyze data, generate pivot tables from natural language</li><li><strong>Google Slides:</strong> Generate presentation decks from documents, create speaker notes, design layouts</li><li><strong>Google Meet:</strong> Take notes, create action items, summarize meetings you missed</li></ul><p>The power move is chaining these together. "Read the last 5 emails from [client], create a summary doc, and draft a Slides presentation for our meeting tomorrow." That is agent behavior. Multi-step, multi-tool, autonomous.</p><h2 id="project-mariner-the-web-browsing-agent">Project Mariner: The Web Browsing Agent</h2><p>Project Mariner is Google's answer to the question "what if AI could use the internet like a human?" It runs as a Chrome extension and can:</p><ul><li>Navigate websites and click through pages</li><li>Fill out forms and complete purchases</li><li>Research across multiple sites and compile findings</li><li>Monitor pages for changes</li></ul><p>In my testing, Mariner handles simple web tasks well. "Find the cheapest flight from Toronto to Miami on these dates" works great. Complex tasks with authentication or CAPTCHAs still trip it up.</p><h2 id="jules-the-coding-agent">Jules: The Coding Agent</h2><p>Jules is Google's coding agent, directly competing with Claude Code and GitHub Copilot. It connects to your GitHub repos and can:</p><ul><li>Fix bugs from issue descriptions</li><li>Write pull requests with tests</li><li>Refactor code across multiple files</li><li>Explain codebases and suggest improvements</li></ul><p>I tested Jules against Claude Code. My honest assessment: Claude Code is still ahead for complex, multi-file tasks. Jules is faster for simple bug fixes and small PRs. I wrote a more detailed <a href="https://aiagentsfirst.com/">coding</a> that covers this.</p><h2 id="gemini-api-building-custom-agents">Gemini API: Building Custom Agents</h2><p>For developers, the Gemini API now supports full agent capabilities:</p><ul><li><strong>Function Calling:</strong> Define tools your agent can use and Gemini decides when to call them</li><li><strong>Code Execution:</strong> Gemini can write and run Python code in a sandboxed environment</li><li><strong>Grounding with Google Search:</strong> Agent can search the web in real-time for current information</li><li><strong>Context Caching:</strong> Store large contexts (like documents) and reuse them across requests cheaply</li></ul><h3 id="gemini-api-pricing-for-agents">Gemini API Pricing for Agents</h3>

For Google Workspace automation and budget-sensitive workloads, Gemini wins. For coding, complex reasoning, and content quality, Claude is still ahead. Most builders use both.</p><h3 id="is-gemini-agents-free">Is Gemini agents free?</h3><p>Gemini in Workspace requires a Google Workspace plan ($12-25/user/month). The Gemini API has a free tier with rate limits. Jules and Project Mariner are in preview (free during preview period).</p><h3 id="can-i-build-custom-agents-with-gemini">Can I build custom agents with Gemini?</h3><p>Yes. The Gemini API supports function calling, code execution, and grounding. You can build custom agents using Python, JavaScript, or any language that can make HTTP requests.</p><h3 id="does-gemini-have-memory-like-claude-code">Does Gemini have memory like Claude Code?</h3><p>Sort of. Gemini API supports context caching (store and reuse large contexts) and you can implement persistent memory using their API. But it does not have a built-in file-based memory system like Claude Code's CLAUDE.md approach. You need to build that layer yourself.</p><h3 id="will-gemini-agents-replace-human-workers">Will Gemini agents replace human workers?</h3><p>For structured, repeatable tasks: they already are. For creative, strategic, and relationship-based work: not anytime soon. The smart play is using agents to handle the repetitive stuff so humans can focus on high-value work.</p>
